# Private vault workflow

Public tree = **method + adapters**.  
Keep live topics, captures, and login state in a **private** clone/fork.

```
research-os/           # public capability framework
<your-private-fork>/   # real topics + library + cookies (never push public)
```

## Day-to-day

1. Research in the private fork.  
2. Upstream framework fixes to public (rules/skills/tools only).  

## Never copy to public

- Live sources/captures/cache, personal spend reports, cookies, tokens, `.env`
