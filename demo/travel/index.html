    跨域是不是做不到？能不能 hack？

    浏览器禁止网页 JS 直连 Groq / OpenAI / Tavily / 机票 API——这是 CORS，不是服务器「忘了开接口」。网页里关不掉它。

    • 不要做的：公开 CORS 代理（Key 会被中间人拿走）、让用户开 --disable-web-security、在我们托管的站点上收集 Key。
    • 本 demo 做的：python3 demo/travel/server.py 只绑 127.0.0.1，把页面和 API 变成同源请求。厂商看到的是你的 IP。
    • 若改成我们卖 Key：请求必须走我们的服务器，那就不再是「用户本机 IP」，而是计量 SaaS——和本页的信任模型相反。

    细节见 demo/travel/README.md。
