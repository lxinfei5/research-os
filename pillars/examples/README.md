## Rule for a new domain file

Must include a **User-surface skeleton** where **each first-screen line states why it is the act** (or the one flip).  
Equal-weight facet tours (timeline, ratings, “areas to consider”) belong only on the audit surface.  
If you cannot write that sentence, the section is not allowed on screen 1.
