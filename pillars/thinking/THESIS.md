# Pillar 3 · Thinking shape

## L0

After evidence exists, **do not dive into local polish**.  
First: **first principles** (purpose + main contradiction) and a **logical space** that proves coverage. Then depth.

This is a **shape contract**, not a forced 1→2→3 pipeline. Adjudications must **exist** and stay **available on the audit surface**; they are not dumped on the user surface (`../output/THESIS.md`). Internal order may jump.

---

## First-principle adjudication

Before building the answer, name:

1. **End purpose** — which user-visible problem improves? Must be able to *reject* irrelevant work.  
2. **Main contradiction** — the one lever this session can move that most changes the end (upstream, high blast, high failure cost).  
3. **Non-negotiable boundaries** — e.g. don’t fake evidence class; human owns irreversible actions.  
4. **Priority rationale** — which axes dominate *this* time (effect, upstreamness, corrosion, reversibility…). **No forever-#1.**

**Main-contradiction discriminator:** if you can fix only one thing, which changes the end most? Trace: (1) wrong → other work void; (2) causal upstream; (3) cross-session debt.

---

## Logical space (coverage)

Answer at least:

- **Atomic object** — one cell, one object type  
- **Homogeneous axes** — one question per axis; MECE inside axis  
- **Relation shape** — partition vs product vs dependency vs priority (don’t call everything “orthogonal”)  
- **Single owner + closure** — every case has an owner or explicit residual  
- **Complementarity & minimality** — each item earns its keep  
- **Interference** — local wins that erode upstream invariants lose  

---

## Counterexamples (attack your own map)

1. **Double-hit** — two owners for one case?  
2. **Zero-hit** — legal case silently omitted?  
3. **Boundary switch** — observable condition to change class?  
4. **Failure penetration** — does fallback rewrite evidence semantics?

---

## Anti-corruption (long-term)

- Prefer **one owner** for each method and each fact.  
- **Delete > add** when complexity doesn’t buy irreproducible floor.  
- Don’t grow a second analysis engine “just to be safe.”

## break_condition

Flat equal-weight brainstorm with no main contradiction; tool-driven categories reverse-engineered from folders.
